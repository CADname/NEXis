Setup Guide

Hazard ZoneOutline the area around the rotating machine that people must not enter.
Hall Sensor LEDDraw a tight ROI around the Hall sensor LED. Blink detection uses repeated brightness changes rather than LED color, so red or green LEDs can be used.
RotorDraw around a moving pulley, disk, or another high-contrast rotating feature.
ADXL345Include the accelerometer and its mounting surface. The live view is compared with the saved baseline.
ACS712 / Hall SensorDraw each visible sensor mounting area. This checks visual changes against the baseline; it is not automatic sensor-type recognition.
